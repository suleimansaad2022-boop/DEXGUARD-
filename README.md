# GUARDYXIS V12

A standalone Solana token research dashboard.

## Included
- Dashboard navigation
- Trending Solana pools via GeckoTerminal
- Mint scanner via DexScreener
- Real OHLCV candlestick rendering when GeckoTerminal returns data
- Basic candle heuristics: doji, hammer, engulfing
- Heuristic risk indicators
- Watchlist saved in browser localStorage
- Local research reports
- Shareable and printable research receipt
- Inline furious guardian artwork/background
- Responsive mobile layout

## Run
Open `index.html` in a modern browser, or deploy it with GitHub Pages/Netlify.

## Notes
- Public API availability, CORS rules, rate limits and endpoint behavior can change.
- Risk indicators and candle notes are educational heuristics, not security audits or financial advice.
- Never enter a seed phrase, private key or wallet recovery information.
